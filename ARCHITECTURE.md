# SHOPICS — ארכיטקטורת המערכת

## סקירה כללית

SHOPICS היא מערכת להשוואת מחירים חכמה שעוזרת למשתמש למצוא את החנות הכי משתלמת עבור מוצר נתון — תוך שקלול **מחיר** מול **מרחק נסיעה**.

המערכת כוללת שני מסלולי כניסה:
1. **חיפוש טקסט** — המשתמש מקליד שם מוצר
2. **סריקת תמונה** — המשתמש מצלם מוצר, AI מזהה אותו

## נוסחת הכדאיות

```
raw_saving  = מחיר_בחנות_שלי - מחיר_בחנות_אחרת
travel_cost = מרחק_בקילומטרים × 0.5₪
net_value   = raw_saving - travel_cost
```

- `net_value > 0` → **משתלם לנסוע**
- `net_value < 0` → **לא משתלם** (הנסיעה עולה יותר מהחיסכון)
- מיון: net_value הגבוה ביותר = ההמלצה הראשונה

## אופטימיזציות

1. **סינון כמשפך** — DB → Haversine → Google Routes (רק 5 קריאות)
2. **Geocoding חד-פעמי** — lat/lng מחושב פעם אחת ונשמר ב-DB
3. **FAISS offline** — מודל E5 רץ מקומית, לא דורש אינטרנט
4. **Confidence threshold** — מונע תוצאות לא רלוונטיות
5. **Dedup** — רשומה אחת לכל חנות ייחודית
